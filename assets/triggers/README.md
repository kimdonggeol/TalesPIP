# 기본 제공 자동 숨김 조건

이 폴더의 `.png` 파일 하나가 자동 숨김 조건 하나가 됩니다.
파일 이름이 설정 창에 표시되는 이름이 되고, `_` 는 공백으로 바뀝니다.

게임 UI는 해상도와 무관하게 픽셀 크기가 같으므로, 이미지 하나가 모든 사용자에게 통합니다.
위치만 달라지는데 그건 프로그램이 찾아서 해상도별로 기억합니다.

## 만드는 법

1. 게임에서 해당 창을 엽니다
2. TalesPIP 설정 창 → `자동 숨김 (화면 감지)` → `화면에서 추가` 로 그래픽을 드래그합니다
3. `python tools/export_triggers.py` 를 실행하면 이 폴더로 저장됩니다

무늬가 거의 없는 조각은 등록되지 않습니다. 다른 화면과 구분이 안 돼서
PIP가 계속 숨어버리기 때문입니다. 글자나 테두리가 들어간 부분을 고르세요.
