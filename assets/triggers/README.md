# 기본 제공 화면 감지 조건

이 폴더의 `.png` 파일 하나가 조건 하나가 됩니다.
**설정 창에는 나타나지 않습니다.** 프로그램이 기본으로 갖는 판단 기준이고,
사용자는 `화면 감지 사용` 체크로 전체를 끄는 것만 할 수 있습니다.

사용자가 설정 창에서 직접 추가하는 조건은 언제나 `hide` 입니다.

폴더가 조건의 방향을 정합니다.

| 폴더 | 뜻 |
|---|---|
| `show/` | 이 그래픽이 보여야 PIP를 표시합니다. 퀵슬롯 바처럼 캐릭터가 접속한 뒤에만 나타나는 UI를 넣습니다 |
| `hide/` | 이 그래픽이 보이면 PIP를 숨깁니다. 오픈마켓처럼 화면을 덮는 창을 넣습니다 |

`show/` 조건이 하나라도 있으면 그 중 하나는 화면에 있어야 PIP가 보입니다.
`hide/` 조건이 걸리면 그쪽이 우선입니다.

게임 UI는 해상도와 무관하게 픽셀 크기가 같으므로, 이미지 하나가 모든 사용자에게 통합니다.
위치만 달라지는데 그건 프로그램이 찾아서 해상도별로 기억합니다.

## 만드는 법

1. 게임에서 해당 화면을 띄웁니다
2. TalesPIP 설정 창 → `자동 숨김 (화면 감지)` → `화면에서 추가` 로 그래픽을 드래그합니다
3. `python tools/export_triggers.py` 를 실행하면 `hide/` 로 저장됩니다
4. `show/` 조건은 파일을 그 폴더로 옮기면 됩니다

무늬가 거의 없는 조각은 등록되지 않습니다. 다른 화면과 구분이 안 돼서
판정이 늘 참이 되기 때문입니다. 글자나 테두리가 들어간 부분을 고르세요.

## 찾는 위치 지정

게임 UI는 대개 화면 가장자리나 구석에 붙어 있습니다.
파일 이름에 `@` 로 위치를 붙이면 그 근처만 뒤져서 훨씬 빠릅니다.

```
퀵슬롯@bl.png     → 좌측 하단만 검색
오픈마켓@c.png    → 가운데만 검색
창고.png          → 화면 전체 검색
```

| 키 | 위치 | 키 | 위치 | 키 | 위치 |
|---|---|---|---|---|---|
| `tl` | 좌측 상단 | `t` | 상단 | `tr` | 우측 상단 |
| `l` | 좌측 | `c` | 가운데 | `r` | 우측 |
| `bl` | 좌측 하단 | `b` | 하단 | `br` | 우측 하단 |

1920x1440 화면에서 퀵슬롯 바(190x24)를 찾는 데 전체는 48ms, 좌측 하단만은 6ms 입니다.

## 이미지 크기

가로나 세로가 48px 미만인 조각은 축소하지 않고 원본 크기로 찾습니다.
퀵슬롯 바처럼 얇고 글자가 작은 그래픽은 절반으로 줄이면 무너져서 일치도가 1.00 에서 0.57 로 떨어집니다.

사용자가 직접 추가한 조건은 설정 창에서 검색 위치를 고를 수 있습니다.
